== Key Implementation Details

=== Feature Entity (`fhs.core.model.entities.feature`)
The `Feature` Pydantic model is the central domain entity.
Key design decisions:

* `business_value_per_conversion` — EUR value per successful conversion (replaces any `revenue` naming)
* `uncertainty` — relative uncertainty as decimal (e.g., `0.3` = +/-30%); drives Monte Carlo spread
* `acceptance_model` — `"rate"` (continuous) or `"binomial"` (per-user yes/no)
* `annual_growth_rate` — compounds business value in multi-year simulations
* `likelihood_of_non_delivery` — delivery risk factor for LaR and sunk-cost calculations
* `development_weeks` — optional sprint capacity for budget optimisation
* `annual_operating_cost` — production running cost deducted from net business value

=== SimulationResult Value Object (`fhs.core.model.value_objects.simulation_result`)
Immutable result of one Monte Carlo run (10,000+ scenarios).
Exposes 30+ computed properties, including:

* `var_95` — 5th percentile of business value distribution (Gain-based VaR)
* `cvar_95` — expected value in the worst 5% of scenarios (Expected Shortfall)
* `business_value_at_risk_95` — `var_95 * business_value_per_conversion`
* `net_value_at_risk_95` — BVaR minus annual development cost installment
* `cvar_95_net_value` — CVaR minus annual installment
* `roi` — `(expected_business_value - annual_installment) / annual_installment`
* `profit_margin` — `net_value / expected_business_value`
* `risk_ratio` — `std / expected_value` — relative spread for risk classification

=== MultiYearResult / YearResult (`fhs.core.model.value_objects.multi_year_result`)
Result of a multi-year Monte Carlo simulation.
Each `YearResult` holds independent scenario draws compounded by `annual_growth_rate`.
Displayed as a fan chart (confidence bands per year) in Notebook 03.

=== FeatureSimulator (`fhs.core.services.simulation.simulator`)
Main orchestration class combining MonteCarloEngine and RiskCalculator.

* `simulate_feature()` — single-year Monte Carlo with configurable distribution
* `simulate_feature_multi_year()` — per-year independent simulations with growth compounding and NPV

=== Monte Carlo Engine (`fhs.core.services.monte_carlo`)
Distribution strategies:

* *Normal* — symmetric uncertainty, most common for adoption rate
* *Lognormal* — right-skewed, models exponential growth potential
* *Beta* — bounded [0,1], models conversion-rate uncertainty precisely
* *Correlated* — Cholesky decomposition for dependent features (same dependency cluster)

=== AdvancedPortfolioService (`fhs.application.advanced_portfolio_service`)
Main application facade using the Sub-Facade pattern:

* `service.risk.*` — loss metrics, Shapley attribution, component risk
* `service.delivery.*` — delivery risk, sprint overruns, profitability
* `service.multi_year.*` — multi-year P&L, NPV/IRR, financial views
* `service.decisions.*` — feature ranking, score analysis, strategy categories
* `service.layers.*` — risk layer simulation, sensitivity, retention

All collaborators share `PortfolioContext` Protocol for type-safe dependency injection.

=== ScenarioService (`fhs.application.scenario_service`)
Application-layer service for YAML-based scenario management:

* `load_scenario()` — loads and validates config, returns `ScenarioContext`
* `save_scenario()` — persists updated features and budget, publishes `ScenarioConfigurationChanged`
* `list_versions()` — returns available config versions for rollback

=== FHSDisplay / show (`fhs.presentation.notebook.widgets.facade`)
Presentation-layer facade built from mixins:

* `_PrimitivesMixin` — markdown, info boxes, KPI cards
* `_CapitalBudgetingMixin` — NPV/IRR tables and charts
* `_RiskMixin` — VaR/CVaR dashboards, risk profiles
* `_PortfolioMixin` — portfolio analysis, budget frontier
* `_DistributionMixin` — distribution comparison guides
* `_DeliveryMixin` — delivery risk, break-even, sunk cost

Instantiated as `show` singleton, imported into notebooks via `fhs.presentation.notebook`.

=== Risk Terminology
[cols="1,3"]
|===
| Term | Definition

| VaR (Gain-based)
| Minimum business value at 95% confidence = 5th percentile of distribution

| CVaR / Expected Shortfall
| Average outcome in the worst 5% of scenarios

| Loss-based VaR
| `expected_value - var_95` — how much value could be lost vs. expectation

| LaR 95%
| Loss at Risk at 95%: 95th percentile of the loss distribution (Notebook 06)

| Break-Even Probability
| Percentage of delivery scenarios with positive profit (Notebook 06)
|===
